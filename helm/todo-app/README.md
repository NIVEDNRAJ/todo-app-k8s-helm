# Todo App Helm Chart

An enterprise-grade Helm chart designed to orchestrate the deployment of the Todo Application stack (Angular UI, .NET 9.0 Backend Web API, and MySQL database) to Kubernetes.

This chart enforces segregation of configurations across exactly **four custom values files** to ensure strict environment partitioning (Dev, Staging, Production).

---

## Chart Folder Layout

```text
helm/
└── todo-app/
    ├── Chart.yaml                  # Chart metadata and versioning
    ├── values-common.yaml          # Infrastructure/Platform values (Shared)
    ├── values-settings.yaml        # Non-sensitive application configuration
    ├── values-secrets.yaml         # Sensitive passwords, keys, and connection credentials
    ├── values-size.yaml            # Resource allocation and replica scaling
    ├── templates/                  # Kubernetes resource templates
    │   ├── deployment-api.yaml     # API Deployment template
    │   ├── deployment-ui.yaml      # UI Deployment template
    │   ├── deployment-db.yaml      # MySQL Database Deployment template
    │   ├── service-api.yaml        # API Service template
    │   ├── service-ui.yaml         # UI Service template
    │   ├── service-db.yaml         # MySQL Database Service template
    │   ├── configmap.yaml          # ConfigMap mapping environment configurations
    │   ├── secret.yaml             # Secret mapping application keys/passwords
    │   ├── pvc.yaml                # PersistentVolumeClaim for database files
    │   ├── ingress.yaml            # Ingress configuration mapping incoming traffic
    │   └── _helpers.tpl            # Standard Helm chart naming and label helpers
    └── README.md                   # Chart documentation
```

## Values Files Responsibilities

Rather than using a single monolithic `values.yaml` file, this chart uses four isolated configuration files:

1. **`values-common.yaml`** (Common Infrastructure):
   Stores settings relating to the Kubernetes cluster hosting platform. (e.g., namespace overrides, global labels, global `imagePullPolicy`, Ingress controller classes, storage classes).
   
2. **`values-settings.yaml`** (Application Settings):
   Stores settings relating to runtime application configurations. (e.g., application ports, database hostnames/names, JWT issuer, JWT audience, image repository/tags, feature toggles).
   
3. **`values-secrets.yaml`** (Sensitive Secrets):
   Stores passwords, security tokens, and encryption keys. (e.g., MySQL root password, JWT secret key).
   
4. **`values-size.yaml`** (Infrastructure Sizing):
   Stores settings relating to capacity and container orchestration footprints. (e.g., replicas, CPU requests/limits, Memory requests/limits, persistent disk storage sizes).

---

## Merging of Values Files

Helm merges multiple values files in the order they are provided via the `-f` / `--values` command-line flags. 
Values defined in later files override those defined in earlier files.

To evaluate, lint, or install the chart correctly, **all four files must be specified** in the correct order:
```bash
helm install todo ./helm/todo-app \
  -f ./helm/todo-app/values-common.yaml \
  -f ./helm/todo-app/values-settings.yaml \
  -f ./helm/todo-app/values-size.yaml \
  -f ./helm/todo-app/values-secrets.yaml
```

## Operations Guide

### 1. Template Rendering (Dry Run)
To compile and print the raw Kubernetes manifests generated by the templates without installing them to the cluster:
```bash
helm template todo ./helm/todo-app \
  -f ./helm/todo-app/values-common.yaml \
  -f ./helm/todo-app/values-settings.yaml \
  -f ./helm/todo-app/values-size.yaml \
  -f ./helm/todo-app/values-secrets.yaml
```

### 2. Linting (Static Analysis)
To perform validation checks on the chart templates and values files syntax:
```bash
helm lint ./helm/todo-app \
  -f ./helm/todo-app/values-common.yaml \
  -f ./helm/todo-app/values-settings.yaml \
  -f ./helm/todo-app/values-size.yaml \
  -f ./helm/todo-app/values-secrets.yaml
```

### 3. Installation
To deploy the Helm release to the cluster:
```bash
helm install todo ./helm/todo-app \
  -f ./helm/todo-app/values-common.yaml \
  -f ./helm/todo-app/values-settings.yaml \
  -f ./helm/todo-app/values-size.yaml \
  -f ./helm/todo-app/values-secrets.yaml
```

### 4. Upgrades (Deploy Updates)
To apply configuration changes or update container images on an active installation:
```bash
helm upgrade todo ./helm/todo-app \
  -f ./helm/todo-app/values-common.yaml \
  -f ./helm/todo-app/values-settings.yaml \
  -f ./helm/todo-app/values-size.yaml \
  -f ./helm/todo-app/values-secrets.yaml
```

### 5. Rollback
If a deployment fails or exhibits issues, roll back to a previous revision:
```bash
# View deployment history and revisions
helm history todo

# Rollback to revision 1
helm rollback todo 1
```

### 6. Uninstallation
To completely tear down the release and remove all associated Kubernetes resources (excluding Retained PersistentVolumes):
```bash
helm uninstall todo
```
